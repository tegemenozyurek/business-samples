# Business Samples

Next.js demo with two business templates:

- **Rez** — appointment booking site + admin panel
- **Sip** — food ordering site + admin panel

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm start` | Start production server |

## Admin

Both templates use:

- Username: `admin`
- Password: `admin123`

Routes: `/rez/admin` and `/sip/admin`

## Deploy

Ready for Vercel. Connect the repo or run:

```bash
vercel
```
